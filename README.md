# 4K IPTV

Android IPTV player for phones and Android TV / Google TV.

## Current features
- Kotlin, Jetpack Compose and Media3 ExoPlayer.
- Responsive interface for touch and TV remote navigation.
- Import an M3U playlist by URL.
- HLS and DASH playback modules.
- Channel search, groups and favorites.
- GitHub Actions debug APK build.

## 4K playback
2160p playback depends on the supplied stream, Android device, display and network. The player does not upscale HD video into genuine 4K.

## Run
Open the project in Android Studio with JDK 17 and Android SDK 35, then run the app module.

GitHub Actions builds a debug APK on each push to main.

## Legal use
This is a player only. Use streams only when you own them or have permission to access them. No TV channel streams are bundled.
